# House Price Prediction

An end-to-end machine learning project that predicts residential
property prices using a Random Forest regression model.

The project demonstrates a complete data science workflow:

- Data preparation
- Feature selection
- Missing-value handling
- Model training
- Model evaluation
- Feature importance analysis
- Model deployment with Streamlit

## Project Overview

The goal of this project is to estimate a home's sale price from
a small set of important property characteristics.

The model uses the following features:

- Overall quality
- Above-ground living area
- Garage capacity
- Basement area
- Number of full bathrooms
- Year built

## Dataset

This project uses the:

**House Prices: Advanced Regression Techniques**

dataset from Kaggle.

The target variable is:

`SalePrice`

The dataset is not included in this repository.

To run the project locally:

1. Download `train.csv` from Kaggle.
2. Place it inside the `data/` directory.
